# Modélisez une infrastructure dans le cloud

Projet OpenClassrooms consacré à la conception d'une infrastructure cloud hybride et à la réalisation d'un pipeline de traitement de données en temps réel.

## Contexte

InduTechData souhaite moderniser son système d'information en intégrant des services cloud tout en conservant une compatibilité avec son infrastructure on-premise existante.

## Objectifs

- Concevoir une architecture hybride on-premise / AWS.
- Intégrer une plateforme de streaming avec Redpanda.
- Produire et traiter des tickets clients en temps réel.
- Analyser les données avec PySpark.
- Conteneuriser le POC avec Docker et Docker Compose.
- Documenter l'architecture et le fonctionnement du projet.
